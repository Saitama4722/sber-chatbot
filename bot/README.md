# Справочный чат-бот для клиентов ПАО Сбербанк

Учебный проект в рамках производственной практики (технологическая
(проектно-технологическая) практика), направление 09.03.03 Прикладная информатика,
профиль "Искусственный интеллект и большие данные".

Бот отвечает на типовые вопросы клиентов банка: карты, вклады, кредиты, ипотека,
переводы, бонусная программа, курсы валют, работа отделений, мобильное приложение,
обслуживание бизнеса. Распознавание темы построено на обработке естественного языка
средствами NLTK и морфологического анализатора pymorphy3.

## Возможности

- нормализация запроса: токенизация, отсев стоп-слов, приведение слов к начальной форме;
- исправление опечаток сопоставлением с внесловарными формами;
- взвешенное сопоставление ключевых слов, редкое слово влияет на выбор темы сильнее общего;
- сравнение с примерами формулировок по мере Жаккара и посимвольному сходству;
- три сценария реакции: уверенный ответ, уточняющий вопрос, сообщение о непонимании;
- три интерфейса: консоль, Telegram, веб-страница.

## Структура

```
sberbot/
    data/intents.json     база знаний: темы, ключевые слова, примеры, ответы
    preprocess.py         предобработка текста
    engine.py             распознавание темы и подбор ответа
    cli.py                консольный интерфейс
    telegram_bot.py       интеграция с Telegram
    web.py                веб-интерфейс на Flask
tests/
    dataset.py            контрольная выборка из 111 формулировок
    evaluate.py           расчет точности и времени ответа
    test_engine.py        модульные проверки
```

## Установка

```bash
git clone https://github.com/Saitama4722/sber-chatbot.git
cd sber-chatbot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Корпуса NLTK (punkt, punkt_tab, stopwords) загружаются автоматически при первом запуске.

## Запуск

Консольный режим:

```bash
python -m sberbot.cli
python -m sberbot.cli --debug     # с выводом темы, оценки и времени ответа
```

Веб-интерфейс:

```bash
python -m sberbot.web
```

Telegram:

```bash
export TELEGRAM_TOKEN=<токен от @BotFather>
python -m sberbot.telegram_bot
```

## Проверка качества

```bash
python -m tests.evaluate     # точность распознавания и время ответа
pytest -q                    # модульные тесты
```

Результат последнего прогона: 107 верных ответов из 111, точность 96,4 процента,
среднее время обработки запроса 4,05 мс.

## Расширение базы знаний

Новая тема добавляется объектом в массив `intents` файла `sberbot/data/intents.json`.
Требуются идентификатор, название, список ключевых слов в начальной форме,
примеры формулировок и текст ответа. Изменение кода не требуется.
